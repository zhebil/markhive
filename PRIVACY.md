# Markhive Privacy Policy

_Last updated: 2026-05-02_

Markhive is a Chrome extension that exports the open `claude.ai` conversation to a Markdown file on your own machine.

## What data Markhive accesses

- **The active claude.ai tab.** When you click the toolbar icon on a `https://claude.ai/chat/*` page, Markhive reads the conversation data the Claude web app already loaded into your browser. It does this in two ways:
  1. By reading the page's IndexedDB cache (the same cache the Claude UI uses), via a content script injected into the active tab.
  2. As a fallback, by calling the `claude.ai` REST API the same way the Claude web app does, using your existing browser session.
- **Your in-extension settings.** The four export toggles (frontmatter, thinking, tool inputs, tool results) and an optional save-folder reference are stored locally with `chrome.storage.local` and `chrome.storage.session`.

## What data Markhive sends

**Nothing leaves your machine.** Markhive has no servers, no analytics, no error reporting, no remote configuration, and no third-party SDKs. The only network traffic generated by the extension is to `https://claude.ai` itself, authenticated by your existing session, to fetch your own conversation. No other domain is contacted.

## What data Markhive stores

- **Locally, in your browser**: the four toggle preferences, an optional File System Access folder handle (if you opted in via "Choose folder"), and a session-scoped cache of the most recent rendered Markdown for the current chat (cleared when the browser session ends).
- **On disk, when you save**: the Markdown file you explicitly download or save via the folder picker. That is it.

## What Markhive never collects

- No personal information beyond the conversation you choose to export.
- No clickstream, page content from other sites, or telemetry.
- No identifiers, advertising IDs, or device fingerprints.
- No cookies or auth tokens are read or stored by the extension code; the Claude API calls rely on the cookies the browser already attaches to `claude.ai` requests.

## Permissions

| Permission | Why |
| --- | --- |
| `activeTab` | Read the conversation data in the active claude.ai tab when you click the toolbar icon. |
| `scripting` | Inject a small content script into the active claude.ai tab to read the page's IndexedDB cache. |
| `downloads` | Save the rendered Markdown file to your Downloads folder. |
| `storage` | Persist your toggle preferences and the optional save-folder reference locally. |
| Host permission `https://claude.ai/*` | Required so Markhive can read the active claude.ai tab and call the Claude API on your behalf. |

Markhive does not request any other host permissions and does not use the `cookies`, `tabs`, `webRequest`, `history`, or `<all_urls>` permissions.

## Children

Markhive is a developer tool aimed at adult users of `claude.ai`. It is not directed at children under 13.

## Changes

If a future version of Markhive ever changes how data is handled, this file will be updated and the version note above will reflect the change.
