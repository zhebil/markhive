# Markhive v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Manifest V3 Chrome extension named Markhive that exports the open `claude.ai` conversation to a local Markdown file with configurable inclusion of thinking, tool inputs, and tool results.

**Architecture:** Popup (vanilla TS + DOM) <-> service worker (calls `claude.ai/api/...` with the user's session cookie) <-> pure renderer (`renderer.ts`, fixture-tested). No backend. No bundler; `tsc` plus a small copy step builds into `dist/`. See `docs/superpowers/specs/2026-05-02-markhive-design.md`.

**Tech Stack:** TypeScript, Manifest V3, Chrome Extension APIs (`chrome.storage`, `chrome.downloads`, `chrome.runtime`, `chrome.tabs`), `node --test` for unit tests.

**Spec:** `docs/superpowers/specs/2026-05-02-markhive-design.md`

---

## Phase Overview

| Phase | Goal | Depends on |
|---|---|---|
| 1 - Skeleton | Loadable empty extension. Build pipeline working. | - |
| 2 - Pure core | `renderer.ts`, `slugify.ts`, `url-parse.ts` with tests against fixtures. No Chrome APIs touched. | 1 |
| 3 - API + service worker | Service worker fetches Claude conversations end-to-end. | 2 |
| 4 - Popup UI | Toolbar popup wires settings, triggers export, surfaces errors, downloads file. | 3 |
| 5 - Polish | Icons, README with manual test checklist, version 0.1.0 tag. | 4 |

Each phase is a separate beads feature issue. Tasks within a phase are concrete enough to commit per task. TDD applies to every pure module in Phase 2; manual verification gates Phases 3-5.

### Task 1.2 - Build script (asset copy)

**Files:**
- Create: `scripts/copy-assets.mjs`

- [ ] `scripts/copy-assets.mjs` copies `manifest.json`, `src/popup/popup.html`, `src/popup/popup.css`, and `icons/` into `dist/`. Watch mode (when `--watch` flag passed) uses `chokidar`.

```js
import { cp, mkdir } from "node:fs/promises";
import { dirname, join } from "node:path";
import chokidar from "chokidar";

const ASSETS = [
  ["manifest.json", "manifest.json"],
  ["src/popup/popup.html", "popup/popup.html"],
  ["src/popup/popup.css", "popup/popup.css"],
  ["icons", "icons"],
];

async function copyOne(src, dest) {
  const out = join("dist", dest);
  await mkdir(dirname(out), { recursive: true });
  await cp(src, out, { recursive: true });
}

async function copyAll() {
  for (const [src, dest] of ASSETS) await copyOne(src, dest);
  console.log("[copy-assets] done");
}

await copyAll();

if (process.argv.includes("--watch")) {
  chokidar.watch(ASSETS.map(([s]) => s)).on("change", copyAll);
}
```

## Phase 3 - Claude API + service worker

**Outcome:** Service worker, given a `chatId`, fetches the conversation JSON from `claude.ai`. Settings round-trip through `chrome.storage`. Manual verification: triggering the call from a debug button or popup logs the JSON.

### Task 3.1 - claude-api.ts

**Files:**
- Create: `src/lib/claude-api.ts`

- [ ] Two functions:

```ts
export async function fetchOrgId(): Promise<string> {
  const res = await fetch("https://claude.ai/api/organizations", { credentials: "include" });
  if (res.status === 401) throw new ClaudeAuthError();
  if (!res.ok) throw new ClaudeApiError(res.status);
  const orgs = await res.json();
  if (!orgs?.length) throw new ClaudeNoOrgError();
  return orgs[0].uuid;
}

export async function fetchConversation(orgId: string, chatId: string): Promise<unknown> {
  const url = `https://claude.ai/api/organizations/${orgId}/chat_conversations/${chatId}?tree=True&rendering_mode=messages`;
  const res = await fetch(url, { credentials: "include" });
  if (res.status === 401) throw new ClaudeAuthError();
  if (!res.ok) throw new ClaudeApiError(res.status);
  return res.json();
}
```

- [ ] Define typed errors: `ClaudeAuthError`, `ClaudeApiError(status)`, `ClaudeNoOrgError`, `ClaudeNetworkError` (catch fetch throw at the call site).

- [ ] No unit test for this module - it is the network boundary; covered by manual verification.

- [ ] Commit: `feat: claude-api module`.
